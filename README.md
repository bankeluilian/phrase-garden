# 搭配之间 · Phrase Garden

GitHub Pages 静态英语学习网站，包含 968 张固定搭配与句型卡片。

## 功能

- 今日学习、词库搜索和挖空复习
- 1、3、7、15、30、60 天间隔复习
- 忘记后 10 分钟回炉，模糊后次日复习
- 学习记录仅保存在当前浏览器，不会同步到 GitHub 或其他设备；清除浏览器数据会丢失记录

## 部署

无需构建。在 Settings → Pages 中选择 Deploy from a branch，使用 main 分支和 /(root)。

词库含 872 条从用户提供的 Arrow 资料整理的搭配及 96 条补充句型。保留资料来源；不表示拥有原资料的再授权权利。复习间隔是实用安排，不是对个人遗忘曲线的精确预测。
